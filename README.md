A one-line office joke for the [One-Line Office Joke](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) competition on make.fun.

## The joke

> Our 'quick sync' is 45 minutes long, has no agenda, and always ends by scheduling another quick sync.

## How it works

Run `main.ts` with Node. It writes exactly that one line (101 characters, no trailing newline) to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), then reads it back to verify it matches exactly.
